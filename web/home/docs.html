먼저 읽으면 좋은 문서

  2. 화면 정의서눌러 볼 화면과 시연 순서를 미리 봅니다.
  3. 계약·청구 코어 기획서(PRD)다른 서비스가 모두 계약과 청구 위에 올라가므로 여기서 범위를 잡습니다.
