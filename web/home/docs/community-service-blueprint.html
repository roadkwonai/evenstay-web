대안 경로 (디지털이 어려운 회원)

  • 모든 회원 화면 아래 "앱이 어려우시면 프런트 02-000-0000 (가상 번호)로 전화하시거나 직원에게 말씀해 주세요. 방 전화로 거실 때는 내선 0번이에요. 직원이 대신 신청해 드려요."(copy 2-0).
  • 신청·취소·예약은 프런트와 직원이 대신 넣고, 회원 화면에 누가 넣었는지 보인다(copy 2-12).
  • 중요 공지는 문자(제목만, 링크 없음, copy 8-1)와 직원의 직접 전함.
  • 대신 처리하실 분(대리인)과 보호자는 신청하지 않는다. 프런트에 말하면 직원이 대신 신청한다 [가설]. copy 3-1 아래 안내는 "…대신 처리하실 분은 프런트에 말씀해 주세요."로 고쳐졌다(반영됨, prd.md 12절 12번).
  • 생활 요청 "그 밖의 일"로 들어온 프로그램 문의는 프런트가 이 모듈 [대신 신청]으로 넣고 생활 요청을 마친다 [가설: 코드 연결 없음].

읽어 낸 것

  • 뒷단이 가장 촘촘한 곳은 취소 한 번에 일어나는 일(잠금, 취소, 승급, 부재 확인, 문자)이다. 한 트랜잭션과 한 아웃박스 행으로 묶는다.
  • 회원이 기다리는 긴 구간(대기 → 승급)은 문자 하나와 상세 화면 문장으로만 알린다. 마감 뒤에는 사람(전화)으로 넘긴다.
  • 공지의 앞단 약속("닿았는지 남는다")은 직원의 직접 전함 기록에 기대므로, 확인 전 목록을 직원이 쉽게 처리하게 하는 것이 핵심이다.

확인할 것

  1. [가설] 장기 부재 대기자 건너뛰기 조건: 예정 복귀일이 회차 날 뒤이거나 모름. 다른 안은 건너뛰지 않고 직원에게 맡기기.
  2. [가설] 대신 예약 때 이용 규칙 확인: 직원이 말로 전한 것으로 기록한다. 회원이 다음에 앱으로 예약할 때 규칙을 한 번 보인다(copy 5-1 이용 규칙 안내).
