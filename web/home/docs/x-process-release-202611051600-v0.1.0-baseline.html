v0.1.0 — 아키텍처 기준본

목차
  1. 확인 범위
  2. 파일

기록 시각: 2026-11-05 16:00 KST

아키텍처 보완 전 공개 문서와 클릭형 프로토타입을 첫 버전으로 기록한다. 기존 공개본 f7208fe의 내용이 기준이며, 이번 버전은 릴리즈 메타데이터만 추가한다.

  • 모듈형 모놀리스와 A/B/C 구성안, 0~5단계 설계, 아키텍처 도식 16장을 보존한다.
  • 실제 서비스 구현물이 아니다. 인물·사업장·금액은 모두 가상이다.
  • 2026-11-05 Codex 검토의 보완 내용은 다음 버전 v0.1.1에 반영한다.

확인 범위

기존 프로토타입 문구 검사와 아키텍처 용어 검사는 통과했다. 클라우드·현장 장비·법령 적용을 실제로 시험한 버전은 아니다.

파일

공개 기준본 아카이브와 SHA-256은 GitHub Release 첨부 파일로 관리한다. 원본 작업 경로와 비공개 문서를 담은 보관본은 공개하지 않는다.
