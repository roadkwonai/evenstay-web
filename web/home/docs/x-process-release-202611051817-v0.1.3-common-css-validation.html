v0.1.3 — 공통 CSS 경고와 상단 영역 보완

목차
  1. 변경 내용
  2. 검증과 호환성

기록 시각: 2026-11-05 18:17 KST

공통 표면의 글자색 상속을 명확히 하고, 서체 수 검사 오탐을 수정했다. 검증 중 재현한 상단 막대의 권한 선택창 겹침과 1280px 줄바꿈도 함께 해결한다.

변경 내용

  • 안내·상세·기록·시트 하단·홈 개관 등 6개 표면에 기존 --fg-default를 명시한다. 부모 상태색이 일반 본문으로 새어 들어오지 않도록 하며 DESIGN.md의 색·서체·크기 값은 바꾸지 않는다.
  • 서체 수 검사에서 숫자 굵기·크기 등 타이포그래피 토큰을 서체 이름으로 세지 않도록 한다. 실제 서체 과다 선언은 계속 검출한다. 업스트림 변경으로 오인하지 않도록 프로젝트 로컬 패치를 기록한다.
  • 홈·소개 사이트의 권한 선택창이 실제 상단 막대 높이를 따라 열리게 한다. 리사이즈와 테마 전환도 반영하며 앱의 기존 높이 측정 경로는 유지한다.
  • 중간 화면 폭에서는 앱 상단의 마크를 접고 테마 버튼과 시연 도구 여백을 압축한다. 시계·시연 기능·접근성 이름·키보드 조작은 유지한다.
  • 공통 색상·서체 검사와 상단 영역의 리사이즈 회귀 검사를 추가하고 웹·릴리즈 기록을 갱신한다.

검증과 호환성

밝은·어두운 테마와 1440px·375px의 24개 색상 계약 검사를 수행한다. 기존 경고의 수정 전 재현과 수정 후 결과, 데모·키보드 검사와 배포 결과는 같은 릴리즈의 VERIFICATION.md, DEPLOYMENT.json에 기록한다.

문서·클릭형 프로토타입의 공통 UI 수정이다. 업무 데이터 구조와 실제 서비스 구현 범위는 바꾸지 않으며 이전 릴리즈와 태그를 보존한다.
