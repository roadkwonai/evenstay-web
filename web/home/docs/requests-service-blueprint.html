현재 상태 (as-is) 요약 [추정]

  • 입주자는 프런트에 전화하거나 지나가는 직원에게 말로 부탁한다. 프런트는 메모하거나 담당에게 전화로 전한다(P-052 [추정]).

  • 정기 청소는 담당 직원의 일정표에 있고, 쉬는 날은 입주자가 말로 알린다 [추정].
  • 비용이 드는 세탁 대행은 별도 장부로 청구서에 옮긴다 [추정]. 현장 확인은 [NEED: 현장 직원 인터뷰].

읽어 낸 것

  • 앞단의 약속(맡은 직원 이름, 다시 열림)은 모두 뒷단의 상태 기록 한 곳에서 나온다. 들어오는 길이 넷이어도 뒷단은 하나라 실패 지점이 길마다 늘지 않는다.
  • 지원 시스템 의존이 몰리는 곳은 "유료 요청 확인" 한 장면(N1 → 아웃박스 → 코어)이다. 그래서 요청 종료와 청구 넘김을 나눠, 코어가 실패해도 회원 확인은 끝난다.
  • 회원이 기다리는 긴 구간(접수 → 배정)은 시간 약속 대신 맡은 직원 이름으로 채운다.
