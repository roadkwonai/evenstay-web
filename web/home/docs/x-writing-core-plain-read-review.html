고치지 않고 남긴 애매한 문구

문구 왜 애매한가 왜 남겼나
입주를 기다리고 있어요. 누가 기다리는지 한 번에 오지 않는다. "아직 입주 전이에요."가 더 쉽다 계약 상태의 회원 말로 정해져 있다(US-04, prd, 코어 용어집, 랜딩 copy)
580,000,000원 0이 많아 소리 내어 읽기 어렵다. "5억 8천만 원"이 쉽다 청구서 금액 표기를 함께 정해야 하는 표시 규칙이라 제안으로 남긴다
퇴거하실 때 "퇴거"가 딱딱하다 D, G copy의 "퇴거하실 날"과 같은 말이다(공용 용어 제안 참고)
보증보험, 전세권 일상어가 아니다 계약서에 적힌 말이고 풀면 뜻이 달라질 수 있다
드시지 않은 식사 빼 드림 명사형으로 끝난다 항목 이름 자리라 짧아야 한다
첫 청구서는 4월분이에요. "4월분"이 조금 딱딱하다 70대에게 익숙한 말이다
이용 목적, 이용 항목, 보관 기간, 동의를 거부할 권리와 거부할 때의 불이익 말이 딱딱하다 법이 알리게 한 항목 이름 후보라 법률 검토 때 정한다

공용 용어 제안

  • "퇴거하실 때", "퇴거하실 날"(코어, D, G)을 "이사 나가실 때", "이사 나가실 날"로 함께 바꾸는 안.
  • "입주를 기다리고 있어요"를 "아직 입주 전이에요"로 바꾸는 안(코어, 랜딩).
  • 회원 화면의 억 단위 금액을 "5억 8천만 원"처럼 쓰는 표시 규칙(지금은 코어 보증금 안내에만 있다).
