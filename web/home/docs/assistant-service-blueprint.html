단계 물리적 증거 이용자 행동 프런트스테이지 백스테이지 지원 프로세스
1. 날짜 버튼 큰 버튼 1 RES가 누른다 — LLM을 부르지 않는다. 버튼 코드 → 도구 core.keyDates. 인자에 회원 ID를 받지 않고 대화의 대상 회원으로 정한다. 코어 권한 검사 후 호출. 도구 호출 1행 기록(행위자, 도구, 권한 결과, 결과 상태) 코어 ContractQuery.keyDates, Authorization.authorize
2. 날짜 답 카피 2-3 답(12월 청구서 나온 날 12-31, 1월 10일까지, 다음 1월 31일 예정) + "확인한 곳" + 버튼 [계약 날짜 보기] RES가 듣는다(화면 읽기 [NEED: 읽어 주기 지원 여부]) 답 틀: 답 한 줄 → 사실 세 줄 이내 → 확인한 곳 서버가 답 틀에 도구 결과를 채운다. 사실 줄마다 어느 결과 값에서 왔는지 출처를 붙이고, 출처 없는 줄은 내보내지 않는다. 비어 있는 날짜 줄은 빼고 "퇴거"라는 말을 꺼내지 않는다 답 틀 렌더러
2a. 납부 기록 (기한이 지났을 때만) 카피 2-3 "언제까지 내요?" 갈래 — "미납", "연체"라는 말을 쓰지 않는다 코어가 주는 납부 상태(계산값)가 있으면 갈래를 고르고, 없으면 "볼 수 없음" 갈래 코어 BillingQuery 납부 상태 (HUB-1 반영)
3. 청구서 버튼 큰 버튼 2 RES가 누른다 — 대상 회원의 가장 최근 발행(ISSUED) 청구서 ID를 서버가 고른다(invoicesOf) → explainInvoice. 청구서 ID는 LLM에서 오지 않는다. 보인 결과마다 코어 감사 READ 1줄 코어 BillingQuery, AuditWriter
4. 청구서 답 카피 2-4: 2,910,000원, 생활비·식비·드시지 않은 식사 3끼 + 확인한 곳 + [이 금액이 이상해요] [직원에게 전하기] RES가 듣는다 금액은 코어 근거의 plain 재료를 그대로 쓴다. 비서는 더하거나 빼지 않는다 답 틀 채움, 대화 턴 2개 기록 코어 Charge.evidence.plain
4a. 코어 응답 실패 카피 6절 "지금은 청구서를 보여 드리지 못했어요." — 프런트 전화 버튼 도구 호출 결과 ERROR 기록, 재시도하지 않는다(회원이 다시 누름) —

흐름 3. 말로 묻기 (의도 분류와 민감 의도)

시나리오: 회원이 [말로 묻기]로 "식비는 왜 이만큼이에요?"라고 묻고, 잠시 뒤 "은행이라는데 돈을 옮기래요"라고 말한다.

단계 물리적 증거 이용자 행동 프런트스테이지 백스테이지 지원 프로세스
1. 말하기 카피 2-2 "듣고 있어요", [다 말했어요] RES가 말한다 들은 말을 답 위에 보인다. [다시 말하기] 기기(브라우저)에서 글자로 바꾼다. 음성 원본은 서버로 보내지 않는다 음성 인식(브라우저 후보 [미정])
2. 민감 의도 먼저 — — — (1) 규칙(낱말 목록: 약·아파·쓰러·돈 옮기·송금·비밀번호·계약 끝·방 옮기·주식 …)이 먼저 본다. (2) 걸리지 않으면 LLM 라우터가 의도 하나를 고른다(정해진 목록 안에서만, JSON 형식 검사). 둘 중 하나라도 건강·금전·계약·투자면 도구를 부르지 않는다 규칙 목록, LLM 어댑터(제공자 [미정]) 또는 녹화 응답
3a. 도구 의도 카피 2-4 "식비는 왜 이만큼이에요?" 답 RES가 듣는다 답 틀 라우터 결과 = 청구 설명, 항목 MEAL_FEE. 서버가 청구서를 고르고 도구 호출. LLM에는 도구 결과를 돌려주지 않는다(답 문장은 서버가 만든다) 코어 explainInvoice
3b. 금전·투자 의도 카피 2-5 금전·투자 답 + [네, 전해 주세요] [프런트로 전화하기] RES가 본다 판단하지 않는다는 한 문장 + 넘길지 묻기 회원이 넘기기 버튼을 누르면 확인 토큰 행(= 넘김 후보)에 실행 인자(전할 말 = 들은 말 원문, 넘긴 이유 = 금전 판단)를 저장한다. 아직 직원에게 보이지 않는다 —
3c. 건강 의도 카피 2-5 건강 답(119·프런트 먼저) RES가 본다 119·프런트 안내가 넘기기 질문보다 먼저 위와 같음, 이유 = 건강 판단 —
3d. 도구 밖·다른 사람·긴 이야기 카피 2-5 표 RES가 본다 모른다/하지 않는다 한 문장 + 버튼 도구 호출 없음. 다른 사람 정보 요청은 의도 OTHER_PERSON으로 기록 —
3e. 두 번 못 알아들음 카피 2-2 "이번에도 잘 듣지 못했어요" — 큰 버튼과 프런트 전화로 돌려보냄 막다른 답 1건으로 센다(North Star에서 빠짐, strategy.md 6절) —
