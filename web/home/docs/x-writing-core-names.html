상표·도메인 확인 범위

2026-11-02에 "살뜰", "온채", "곁에"를 웹에서 검색했다. 같은 이름의 앱이나 서비스는 찾지 못했고, 가장 가까운 것은 B2B 메시지 앱 "온채널"이었다. 웹 검색은 상표 조사가 아니다. 실제로 쓰려면 KIPRIS에서 지정상품(9류 소프트웨어, 36류 부동산·금융, 42류 SaaS, 44류 돌봄)별로 검색해야 한다 [미확인]. 도메인 등록 여부도 확인하지 않았다 [미확인]. 포트폴리오 안에서만 쓰는 이름이라면 위험은 낮다. [지원 회사]나 [지원 회사]의 상표는 쓰지 않는다.

플랫폼 이름 후보 5개

이름 이유 브랜드 적합성 기억성 상표·도메인
살뜰 "살뜰하다"는 빈틈없이 정성껏 챙기면서 알뜰하게 꾸린다는 뜻이다. 돌봄(챙김)과 돈 관리(알뜰)를 한 단어로 묶는다 회원용 이름으로도 그대로 쓸 수 있어 하나의 브랜드로 간다. 차분하고 존중하는 목소리와 맞다 2음절, 일상어. 70~80대에게 익숙하다 웹에서 동일 서비스 미발견. 일상어라 식별력이 약할 수 있다 [미확인]
온채 온(모든·따뜻한) + 채(집을 세는 단위). "모든 채를 한 기준으로"라는 다사이트 운영의 뜻 운영 도구 이름으로 단정하다. 회원용으로는 뜻이 바로 전달되지 않는다 짧지만 조어라 처음엔 설명이 필요하다 "온채널"과 소리가 겹친다
한결 "한결같다". 사이트가 늘어도 같은 기준 운영 일관성 메시지와 맞다 익숙한 말 같은 이름 브랜드가 많을 가능성이 높다 [미확인]
마루 한옥에서 모든 방을 잇는 중심 공간. 여러 모듈을 잇는 코어 구조 은유가 좋다 매우 쉽다 흔한 이름이라 상표 충돌 가능성이 높다 [미확인]
곳간 집안의 살림을 보관하는 곳. 계약·청구 원장 돈 쪽으로 치우쳐 돌봄 모듈과 어울리지 않는다 쉽다 [미확인]

회원·보호자용 이름 후보 5개

이름 이유 브랜드 적합성 기억성 비고
살뜰 비서 / 살뜰 가족 플랫폼 이름을 그대로 쓴다. 회원 앱은 "살뜰 비서", 보호자 화면은 "살뜰 가족" 하나의 이름으로 운영·회원·보호자가 같은 서비스를 가리킨다 높다 단일 브랜드
곁에 "곁에 있어요". 부를 수 있는 사람이 곁에 있다는 느낌 따뜻하지만 돈·계약 기능과는 거리가 있다 높다 웹에서 동일 서비스 미발견
챙김 일정·약·청구를 챙겨 준다는 행동 그대로 기능이 바로 보인다 높다 흔한 말이라 식별력 [미확인]
말벗 쉽고 친근하다 쓰지 않는다. 설계상 정서적 말벗 기능을 넣지 않기로 했다(과의존 위험. P-026, ai-assistant.md 0절) — 탈락
이웃집 가까운 사람에게 묻듯이 다사이트 운영 메시지와 맞지 않는다 보통 보류

  • 돌봄과 돈 관리를 한 단어로 담는다. 금융 기능(I-29, I-30, I-31)과 비서(G)가 같은 플랫폼 안에 있는 통합안과 맞다.

모듈 slug (코드·폴더, 바꾸지 않음) 직원 화면 이름 회원·보호자 화면 이름

한글 이름

이름 뜻과 이유 어디에 발음·기억 (70~80대) 검색 결과
늘곁 늘 + 곁. "언제나 곁에 있다." 부르면 사람이 이어 준다는 비서·보호자 기능과 맞다 회원·보호자 2음절 우리말, 쉽다 같은 이름 서비스 미발견
한채 한 + 채(집을 세는 단위). "여러 사업장을 한 채처럼 한 기준으로." 다사이트 코어의 뜻 그대로 운영 쉽다. 처음 들으면 뜻 설명이 한 번 필요 같은 이름 서비스 미발견
늘품 순우리말 "늘품"은 앞으로 좋게 발전할 품성이라는 뜻이고, "늘 품는다"로도 읽힌다. 돌봄과 성장 운영·회원 단일 2음절, 부드럽다 같은 이름 서비스 미발견
도란 "도란도란" 정답게 이야기하는 모양. 말로 묻는 비서와 어울린다 회원(비서) 쉽다 국내 시니어 서비스 미발견. 해외 시니어폰 브랜드 Doro와 소리가 가깝다. 주의: 말벗 인상이 강해 정서적 과의존을 피하려는 설계(업무형 비서)와 어긋날 수 있다

이름 뜻과 이유 어디에 한국어 발음 검색 결과

쓸 수 있는 후보 (검색에서 같은 이름 미발견)

이름 한글 읽기 뜻과 이유 어디에 주의
Evenstay 이븐스테이 even(고르게, 공정하게) + stay(머묾). 사업장이 늘어도 같은 기준, 근거가 붙은 공정한 청구라는 코어의 약속 그대로 운영 + 단일 브랜드 없음
Staylane 스테이레인 stay + lane(길). 입주 → 거주 → 단계 전환 → 퇴거로 이어지는 계약의 길, 상태 전이 설계와 맞다 운영 없음

Homeroot 홈루트 home + root. 사는 곳에 뿌리내리고 오래 산다는 뜻. 계속 거주(aging in place) 회원·보호자 없음. 2음절씩 끊겨 말하기 쉽다
Staykind 스테이카인드 stay + kind(다정한). 다정하게 머무는 곳 회원·보호자 없음
Lumastay 루마스테이 luma(빛) + stay. 밤에도 켜진 불빛, 안심 회원·보호자 없음
Hearthly 허슬리 hearth(집의 중심) + -ly 운영 Hearth 회사 2곳. 한글 읽기가 hustle처럼 들린다
Tendwell 텐드웰 tend(돌보다) + well 회원 시니어 돌봄 소프트웨어 Tendly와 비슷
Hearthkey 허스키 hearth + key 운영 한글 읽기가 "허스키"(개 품종)와 같아 오해 소지
Oakhaven 오크헤이븐 oak(튼튼함) + haven(안식처) — 같은 이름 미발견. 다만 "-haven"은 해외 시설 이름에 흔해 소프트웨어보다 시설 이름처럼 들린다
