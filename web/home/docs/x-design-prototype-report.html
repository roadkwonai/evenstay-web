여는 법

저장소 루트에서 python3 -m http.server 4173 --directory design/prototype을 실행하고 http://localhost:4173/ 을 연다. 위 막대에서 계정, 시계, 시드 초기화, 문자 로그, 화면 폭을 바꾼다. 오른쪽 장면 안내의 [이 단계 열기]는 시계·계정·화면을 옮기고, [자동으로 누르기]는 정의된 대로 누른다.

직접 확인한 것과 못 한 것

  • 진행기가 실제 DOM 클릭으로 전 단계를 두 폭에서 눌렀다. 내장 브라우저 마우스·키보드로는 시드 초기화, 계정 바꾸기, 회원 첫 화면, 생활 요청 한글 입력까지 눌렀다.
  • test/start-states.mjs로 시작 상태 네 가지를 막대에서 눌렀다. 시계가 2026-10-01, 11-10, 12-07, 2027-01-05로 맞고, 새로 고침 뒤 상태가 그대로이고, 되돌린 뒤 41장면을 두 번 다시 돌려 실패 0, 콘솔 오류 0이다.
  • 사람이 모든 장면을 손으로 누르지는 않았다. 실제 휴대폰 기기로 보지 않았다. 전체 렌더 sloplint는 시간 초과로 끝나지 않았다.
  • 시작 상태는 앞 장면을 다시 눌러 만들어서 코어 리셋 정의와 값이 조금 다를 수 있다.
