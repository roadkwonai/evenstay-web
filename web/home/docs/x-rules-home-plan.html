목적

처음 온 사람이 이 프로토타입이 무엇이고 어디까지 만들었는지 한 번에 알고, 권한별 화면, 소개 사이트, 문서, 아트보드, 근거 자료로 바로 가게 한다.

주소

  • /(design/prototype/index.html): 메인 홈. 지금 앱 셸은 app.html로 옮긴다.
  • home/*.html: 홈의 다른 페이지. home/docs/<이름>.html: 문서 페이지. 모두 생성물이다. 원본은 고치지 않는다.
  • site/: 소개 사이트(그대로).

정보 구조(위 내비게이션 6칸)

칸 페이지 내용
홈 index.html 처음 보는 사람이 1분 안에 이해하게 한다: 어떤 문제를 푸는 서비스인지, 누가 쓰는지, 무엇을 설계했는지(권한별 화면, 기획 문서, 아트보드, 기술), 어디부터 보면 좋은지. 맨 위 한 줄에 "이름, 사업장, 금액은 모두 가상입니다". 숫자는 파일에서 센다.
권한별 화면 home/roles.html 회원, 대리인, 보호자, 프런트, 생활 지원, 간호, 야간 당번, 사업장 책임자, 경리, 본사, 소유주 11묶음. 묶음마다 볼 수 있는 것 설명과 대표 바로가기. 22개 계정 전체는 펼쳐서 본다
화면 찾아보기 home/screens.html 페이지 75개를 서비스와 이용자로 거른다. 41개 시연 단계 목록도 탭으로 둔다
문서 home/docs.html + home/docs/*.html 모듈 7개의 8종 문서, 화면 정의서, 프로젝트 개관, 용어집
근거 home/research.html + 문서 페이지 조사, 아이디어 평가, 구조 검토, 결정 기록
아트보드 home/artboards.html 모듈별 데스크톱·모바일 보드
기술과 스킬 home/tech.html 프로토타입에 쓴 것 / 설계만 한 것 두 칸. 스킬은 호출 기록이 있는 것만
제작 히스토리 home/history.html 외 4쪽 여정(단계별 입력, 스킬, 문서, 결정), 프롬프트 원문, 스킬, 설치한 것, 이미지와 영상. 기록의 범위와 가린 값은 밝히고 진행 관리 말투는 쓰지 않는다.
소개 사이트 site/index.html로 가는 길 홈과 권한별 화면 아래에 페이지별 바로가기

앱 바로가기

  • app.html?as=<계정>&go=<화면>: 그 계정의 그 화면을 연다. 진행한 기록이 없으면 41단계를 마친 상태(data/end-state.json)를 불러온다.
  • app.html?beat=<순서>: 그 순서 앞까지 다시 눌러 진행하고 그 순서를 연다(화면이 그 시각에만 의미 있을 때). 최대 약 10초, 안내를 띄운다.
  • app.html?x=<번호>: 41장면 밖 화면을 마친 상태에서 연다.
  • 주소를 읽은 뒤 쿼리는 지운다. 새로 고침은 저장 상태를 쓴다.
  • 바로가기 목록은 data/app-map.json에 생성한다. 손으로 쓰지 않는다.

설명 기능

help.js와 같은 방식(포커스 가두기, Esc, 복귀, 터치 시트)을 홈용으로 쓴다. 화면 설명은 strings/help.json을 그대로 쓰고, 권한 설명, 문서 종류, 기술, 용어 풀이는 strings/home.json과 용어집에서 읽는다.

문구와 숫자

  • 문장은 strings/home.json. 생성기와 홈 스크립트에 한글을 두지 않는다.
  • 숫자(화면 수, 시연 단계, 키 수)는 파일에서 뽑는다. 시험 결과(design/home/test-results.json)는 기록으로만 남기고 화면에는 보이지 않는다. 남은 일 자료(design/home/facts.json의 remaining, undecided, mismatches)도 내부 기록이다.

만드는 순서

  1. 앱 이동과 주소 바로가기, 지도와 끝 상태 생성(design/home/build-map.mjs)
  2. 아트보드 이미지, 사실 자료(design/home/facts.json)
  3. 문서 생성기와 페이지(design/home/build.mjs)
  4. test/visit-home.mjs, 기존 시험 재실행, 새 컨텍스트 검수

시험 계획

test/visit-home.mjs 폭 1440, 390: 모든 내부 링크, 권한별 바로가기가 맞는 계정과 화면을 여는지, 화면 75개 바로가기, 문서 페이지 전체와 문서 안 링크, 모달과 툴팁, 가로 넘침, 콘솔 오류.
