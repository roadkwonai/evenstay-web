safety — 안심 알림 (Evenstay Safety)

목차
  1. 꼭 지킬 규칙
  2. 하지 않을 것

이 문서에 나오는 용어

누르면 용어집의 풀이가 열립니다.

꼭 지킬 규칙

  • 시스템은 판단하지 않는다. 화면과 보호자 문장에는 관찰된 사실과 시각만 쓴다. 판단 단어(낙상, 쓰러짐, 응급, 위험, 감지했습니다, 배회 등)는 쓰지 않고, CI에서 금지어 검사를 한다(prd.md KR3).
  • 등급은 즉시 확인 / 확인 필요 / 기록만. 상태 판단과 119 신고는 직원이 한다.
  • 보호자에게 가는 결과는 D HealthFeedCommand.post로 올린다(본문은 D가 스냅샷으로 보관, ADR-S3). 올리지 않는 경우는 withhold의 이유 두 가지뿐이고, 119·병원 이송 기록은 회원 요청만 된다.
  • 비상 연락처는 B에 복사하지 않고 코어 EmergencyContactQuery로 매번 읽는다(ADR-S4).
  • 다른 모듈은 core/api, family/api로만 쓴다. 스키마는 safety만 쓴다.

하지 않을 것

  • 상태 판단(낙상·응급 여부), 119 자동 신고, 의료 판단. 3차까지 아무도 확인하지 않아도 시스템은 신고하지 않는다
  • 감지 알고리즘, 영상·소리, AI 이상 탐지
  • 진단명·병명·투약 입력 칸, 비상 연락처 전화번호 저장, 출입 카드 번호 원문 저장
  • 보호자 동의 저장, 보호자 화면, 보호자 문자 발송(모두 D)
  • 문자에 내용·"건강"이라는 말·링크 넣기
  • 실제 기기·출입통제·안부 전화·푸시·문자 업체 연동(시뮬레이터와 목업까지)
  • 간호·요양 기록, 시설 밖 독거 가구 관제, 효과 수치 주장
