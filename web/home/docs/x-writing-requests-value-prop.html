원칙: 효과 수치와 처리 시간 약속을 쓰지 않는다. 데모로 보여 줄 수 있는 사실만 쓴다. 급한 일과 몸이 불편한 일은 안심 알림·호출벨·프런트 전화로 간다는 경계를 문장에 남긴다.

기준 문장

입주자가 말한 생활의 부탁을 한 목록으로 받아 맡을 직원에게 나누고, 마칠 때까지의 기록과 입주자의 확인을 남기는 모듈.

이용자별 가치 제안

1. 입주 회원 (U1) 고장, 청소, 세탁, 외출 차량, 병원 동행, 불편한 점을 큰 버튼 하나로 올린다. 누가 맡았는지 직원 이름으로 보이고, 직원이 마치면 회원님이 "다 됐어요"를 눌러야 끝난다. 아직이면 [아직이에요] 한 번으로 다시 전해진다. 앱이 어려우면 프런트 전화, 지나가는 직원, Evenstay 홈 비서에게 말해도 같은 요청으로 올라간다.

2. 보호자 (U3) 멀리 있어도 부모님 방의 고장이나 불편을 Evenstay 패밀리에서 전한다. 회원님이 허락한 범위에서만 올리고 볼 수 있고, 보호자가 올린 요청은 회원님 화면에 "딸 김지민 님이 요청했어요"로 보인다. 허락은 Evenstay 패밀리의 "생활 요청" 항목으로 받는다 (사용자 "추천대로", 2026-11-03). 비용이 드는 요청은 회원님이나 대신 처리하실 분이 확인한 뒤에 접수된다 [가설: 기획에서 확정].

3. 현장 직원 (U4: 프런트, 시설, 청소·세탁, 운전, 생활 지원) 전화로 들은 부탁을 그 자리에서 대신 등록하면 담당 팀으로 바로 간다. 내 일, 배정 전, 기한 지남이 한 목록에 있어서 오늘 어느 호실에 무엇을 하러 가는지 안다. 몸이 불편하다는 내용이 섞여 오면 [안심 알림으로 옮기기]로 넘긴다. 무엇을 옮길지는 직원이 정한다.

4. 사업장 책임자 (시설장, 챔피언·결정권자) 종류별 열린 요청 수와 기한 지남 건수를 운영 현황 대시보드에서 본다. 주 2회 청소와 월 점검은 일정에서 자동으로 만들어지고, 회차마다 마침·쉼·못 함과 이유가 남는다. 비용이 드는 요청은 입주자가 확인한 뒤 코어 청구 항목이 되어 청구서에 근거로 붙는다.

5. 면접관·Tech Lead (포트폴리오 독자) 들어오는 길이 넷(회원 앱, 보호자 화면, 프런트 대신 등록, AI 비서 넘기기)인 요청을 한 모델과 한 상태 기계로 모았다. 상태 전이(접수 → 처리 중 → 완료 → 입주자 확인, 다시 열림, 확인 없이 닫힘), 팀 배정과 처리 기한, 일정에서 회차를 만드는 정기 작업, 확인 시점에 생기는 청구 항목을 데모로 따라갈 수 있다. 다른 모듈(비서, 보호자 포털, 코어 청구, 대시보드)이 가리키던 빈 받는 곳을 채운다 [사실: coverage review 4-1 N1 행].

쓰임새별 짧은 문장

쓰임 문장
포트폴리오 한 줄 (README 첫 줄) 시니어 레지던스의 생활 요청(수리·청소·세탁·외출 차량·병원 동행·의견)을 한 큐로 받아 배정하고, 입주자 확인까지 남기는 작업 지시 모듈
데모 시작 안내 회원 화면에서 "화장실 전등이 안 켜져요"를 올려 보세요. 직원 화면에서 맡고 마치면, 회원 화면에 확인 버튼이 생깁니다.
직원 첫 화면 안내 오늘 맡은 요청 3건, 배정 전 2건이 있습니다. 전화로 받은 부탁은 [대신 등록]으로 올려 주세요.
책임자 정기 작업 화면 상단 정기 작업은 정한 일정에 맞춰 요청으로 만들어집니다. 회차마다 마침, 쉼, 못 함과 그 이유가 남습니다.
회원 생활 요청 첫 화면 고칠 것이나 필요한 일을 알려 주시면 맡을 직원에게 전해요.
보호자 생활 요청 위 한 줄 이은숙 회원님이 허락하신 생활 요청이에요.

쓰지 않기로 한 문장 (근거가 없어서)

하고 싶은 말 쓰지 않는 이유 쓰려면 필요한 근거
"24시간 안에 처리해 드립니다" 처리 시간을 약속할 근거가 없다. 기한은 사업장 설정값이다 사업장의 실제 처리 기준과 이행 기록
"요청 처리 시간을 절반으로" 측정한 적이 없다 도입 전후 접수 → 완료 시간 기록
"놓치는 요청이 없습니다" 직원이 대신 등록하지 않은 말은 시스템이 알 수 없다 해당 없음(보장 문구는 쓰지 않음)
"AI가 요청을 알아서 분류합니다" 비서는 직원에게 전할 뿐이고 종류와 담당은 직원이 정한다 해당 없음(설계 원칙상 쓰지 않음)
"입주자 만족도가 올라갑니다" 만족도를 잰 적이 없다 입주자 설문 전후 비교
"현장에서 요청이 자주 누락됩니다" 국내 현장 사례를 확인하지 못했다(P-052는 추정) 종사자 인터뷰 1~2명의 실제 사례
"병원 진료까지 챙겨 드립니다" 이 모듈은 일정과 이동만 다룬다. 진료는 의료 행위라 기능으로 만들지 않는다 [사실: decisions 2026-11-03] 해당 없음
