모든 문구에 적용한 규칙

  • 해요체, "회원님". 면접관 섹션(LND-11)만 합쇼체 포트폴리오 말투다 [사실: screen-spec 1절]. 입주 전 방문자에게 바로 말하는 히어로는 "내"를 쓰거나 호칭을 뺀다 [가설: 2026-11-04 검수].
  • 지어내지 않는다: 효과 수치, 후기, 입주자 수, 정원, 면적, 가격, 수상, 인증, 협력 병원, 경력·자격·학력, 설립 연도, 운영사 이름 [사실: 허브 지시, handoff 카피 세션 절].
  • 운영 확인 항목(간호 인력 상주, 밤 근무 직원 수, 응급처치 교육, 직원 병원 동행 여부, 협력 의료기관, 식사 시각, 영양사, 원산지, 프런트 운영 시간, 방문 상담 시간)은 문장에 넣지 않고 빈 칸도 보이지 않게 한다 [사실: U-17].
  • 진단, 치료, 모니터링, 감시, 알람, 즉시 출동, 숙소 체크, 응급, 위험, 낙상, 쓰러짐, 배회, 미납, 연체, 퇴소, 판정을 쓰지 않는다. 진단·치료는 "병원과 119가 해요" 경계 한 줄만 둔다 [사실: U-14, screen-spec 7절]. 넘김 기준 시간(5분)은 숫자 없이 "바로 받지 못하면"으로 쓴다 [사실: U-15]. 안부 방문은 주기·시간 숫자 없이 쓴다 [사실: U-25].
  • 메인 순서는 생활(공간, 식사, 여가) 먼저, 안심·건강 지원은 뒤다 [사실: screen-spec 2절]. 이 문서도 화면 순서로 적었다.
  • 식사는 "예시 식단"으로 밝히고 "의무식", "의료식", "치료식", "건강식", "맞춤 영양"을 쓰지 않는다. 식이 선택은 "상담 때 말씀해 주세요" 한 줄만 둔다 [사실: U-19, U-21, U-23].
  • 사진·영상에는 AI 생성 표기, 전화번호에는 "가상 번호", 주소에는 "가상 주소", 상담 폼에는 보내지 않는 데모라는 안내를 붙인다 [사실: 허브 지시, prd 성공 기준].
  • 이모지를 쓰지 않는다. 버전을 말할 때 "판"을 쓰지 않는다. 재촉하는 말("지금 바로", "놓치지 마세요", "마감 임박")을 쓰지 않는다.
  • 사람은 모두 가상이다. 직원은 시드 이름(센터장 최영미, 프런트 최민수, 생활 지원 김하진)을 쓰고 식당 직원은 이 문서에서 정한 송은주다 [사실: U-11 / 가설: 식당 직원 이름]. 회원 예시는 앱 시드의 이은숙 회원님이다 [사실: B·D copy 시드].
