Evenstay 서비스를 구현하기 위한 PRD는 만들어져 있는지 검토해주고 브랜드 가이드라인과 디자인 시스템 사용해서 MVP를 위해 필요한 화면 정의도 별도 문서로 해줘. md파일 형식으로 만들어줘.

랜딩페이지를 먼저 기획하고 PRD 와 화면정의서부터 만들고 landing-page-design 스킬로 랜딩페이지 프로토타입을 제작하고 랜딩페이지의 애니메이션 적용과 검수는 emil design skill 들을 활용해서 적용해줘 랜딩페이지 상단 메인화면에는 브랜드와 서비스에 어울리는 시니어가 안전하고 편안하게 Evenstay 시설을 이용하고 뷰가 좋고 깨끗하고 깔끔한 Evenstay 시니어 숙소에서 편안하게 책을 보거나 여가를 보내면서 휴식을 취하고 있는 시니어 영상도 포함되면 좋겠어 하나의 영상만 나오는게 아니라 여러개의 영상들이 순차 적으로 나오게 만들어줘 따뜻하고 친절하게 대응하는 이븐스테이 직원들의 이미지들을 gpt-image 로 생성하고 higgsfields 영상으로 제작해서 배치해

그외 필요한 일러스트, 아이콘, 마스코트등 이미지들을 모두 gpt-image 로 제작하도록 먼저 기획 하고 모두 생성해서 배치할 수 있도록 해줘
