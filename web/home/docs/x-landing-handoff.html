한 줄 요약

입주를 고민하는 시니어 본인과 보호자 자녀에게 Evenstay에서의 활발하고 편안한 생활(공간, 식사, 여가)을 먼저 보여 주고, 건물·숙소·직원·생활 요청·안심·건강 지원·오시는 길을 한 시설의 모습으로 이어 보여 주며, "회원님이 정하고, 가족은 허락한 소식만 보고, 중요한 일은 사람이 정한다"를 알리고 상담 신청·전화로 이어 주는 소개 사이트. 면접관에게는 메인 끝에서 프로토타입으로 가는 문을 둔다 [가설].

  • 메인 섹션 순서(지시 1): 히어로 → 공간과 하루 → 식사 → 여가와 모임(LND-15, 새로) → 약속 세 가지 → 직원 → 회원님이 쓰시는 앱, Evenstay 홈 → 가족이 쓰는 앱, Evenstay 패밀리 → 도움이 더 필요해질 때 → 안심·건강 지원 → 앱이 어려우시면 → 앱이 혼자 정하지 않아요 → 상담 → 면접관 안내 → 푸터. 히어로 다음 세 섹션이 모두 생활이고, 안심·건강 지원은 열한째다(레드팀 3 기준 통과). 메인 회원 앱 섹션(LND-05)의 셋째 기능을 안심 알림에서 생활 요청으로 바꾸고, 안심 알림 화면은 LND-13으로 옮겼다.
  • 낡은 표시 정리(지시 2): [미정: B 검토 중]을 모두 B 기획 기능으로 바꿨다: 병원 동행 기록 F21, 안부 방문 F22, 장기 부재 동안 알림 멈춤 F23(모두 P1). 생활 요청(N1)을 생활 페이지 SITE-LIFE-05와 메인 LND-05에 넣고, 보호자 생활 요청 허락(D F20)을 메인 LND-06의 다섯째 항목으로 넣었다. 커뮤니티(N2)는 LND-15, SITE-LIFE-03, SITE-FAC-02에 연결 자리를 두었고, N2 기획 승인 뒤 앱 캡처 CAP-10을 CMN-02(이번 주 프로그램)로 정했다. 공지·행사 소식은 "넣지 않음"에서 "N2 연결 자리"로 바꿨다.

evenstay 세션(디자인·클릭형 프로토타입, 승인 뒤)

  • 소개 사이트도 모든 페이지를 클릭형 프로토타입으로 만든다(사용자 결정 2026-11-04). 페이지 사이 이동, 메뉴, 상담 폼 상태(입력 → 오류 → 보내는 중 → 접수 뒤 안내), FAQ 펼침, 식단표 요일 고르기, 숙소 사진 넘기기, 히어로 영상 일시정지와 양쪽 화살표가 실제처럼 동작해야 한다.
  • 스킬 순서(evenstay/CLAUDE.md 디자인 스킬 지침): 기본 지침(web-design-engineer, build-awwwards-quality-sites) → landing-page-design으로 구성 → 에셋 생성(gpt-image-api, higgsfield, gpt-image) → emil 계열(emil-design-eng 기준, animate, review-animations)로 모션 → 새 컨텍스트에서 critique 3종 이상 검수 → sloplint.

  • 이미지 도구는 asset-plan.md 5절 도구 칸을 따른다. gpt-image-api는 키 이미지, 인물 시트, 영상 원본, 고품질 사진 6장(5-5절)에만 쓰고, 나머지는 gpt-image에 키 이미지를 참조로 넣는다. 키 대조 검수에서 맞지 않는 장만 gpt-image-api로 올린다.

인수 조건(프로토타입 검수 때 확인) [가설]

prd.md 4절 성공 기준 1~9를 그대로 쓴다. 요약:

  • 메인 히어로 다음 세 섹션이 생활(공간, 식사, 여가)이고 안심·건강 지원은 뒤에 있다.
  • 메인 히어로 영상 소리 없음, 일시정지 버튼과 양쪽 화살표(키보드·터치), 영상별 지속 시간 띠, 현재 영상 설명, 움직임 줄이기·데이터 절약에서 포스터만. 390폭 첫 화면에 주 버튼이 보임.
  • 모든 페이지 끝에 상담·전화 띠(입주 상담 페이지 제외), 가상 번호·가상 주소 표시.
  • 화면 글자와 대체 텍스트에 판단 단어 0, 이모지 0, 효과 수치·후기·입주자 수·정원 수·면적·가격·수상·인증·협력 병원 0. 운영 확인 전 항목(U-17)이 사실처럼 쓰이지 않았다.
  • AI 생성 표기가 메인 히어로, 사진이 있는 페이지, 푸터에 있음.
  • 같은 건물·재질·유니폼·얼굴(키 이미지 대조).
  • 식사: 상차림 사진이 같은 식탁·그릇·빛, 식단표에 "예시 식단" 표시, 영양 수치·칼로리·원산지·영양사·식비 금액 없음, "의료식"·"치료식" 없음.
  • 안심·건강 지원: 진단·치료를 한다는 문장, 도착 시간 약속, 지어낸 간호 인력·협력 병원·자격이 없음. 구급차·병상·의료 장비 이미지 없음.
  • 상담 폼: 건강 정보 칸 없음, 동의 미리 체크 안 됨, 보내지 않는 목업이라고 화면에 밝힘. 약도는 일러스트, 실제 지도 없음.
  • 1024px 이상과 640px 아래 두 폭, 글자 200%에서 가로 스크롤 없음.
