## 5. 확인하지 못한 것

- Design 캔버스의 CAP-1~9 실제 화면(문구, 캡처 상태, 보이는 칸)은 열어 보지 못했다. 대체 텍스트와 캡처가 맞는지는 R-05·G-05 외에는 [미확인]이다.
- 이미지는 key-tone, key-uni, key-bldg, key-int-r 네 장만 직접 봤다. key-int-c, key-meal, per-*, ill-1, mas-*는 파일 존재와 `prompts.md`만 확인했다. 인물 시트 PER-SR3는 폴더에 아직 없다(생성 중으로 보임) [추정].
- `prompts.md`가 KEY-BLDG·INT-C·INT-R·MEAL·UNI 2회차를 "사용자 확인 대기"로 적고 있다(decisions.md:95·96은 확정). 이 파일은 `evenstay` 쪽이라 이번 범위 밖이다. 허브가 알려 주면 좋다.
- 모듈 문서는 이 검토에 필요한 부분만 읽었다. B copy 4절, D copy 2-3·4-1·4-2·4-6·3-4, N1 copy 2절과 names, N2 names와 copy 일부, 코어 copy 3절, B prd 7절. 각 모듈의 tech-design, user-stories, roadmap은 읽지 않았다(B US-16만 확인).
