## 흐름 (모두 [가설], 금액 시드 변화 없음)
- 실제 결제는 없다. 목업에 입력 칸이 없고 성공, 실패, 그만두기만 있다.
- [내기]는 CORE-08 카드 바로 아래 첫 행동이다. 미수와 일부인 발행 청구서의 본인과 PAY 대리인에게만 보인다.
- CORE-16: 확인 → 목업 → 결과. 금액은 서버가 정한 남은 금액이고 일부 금액은 고르지 않는다.
- 건별 결제 진행 중이면 [내기] 자리에 진행 중 안내가 나온다. 자동이체 결과 대기면 [내기] 없이 안내와 프런트 전화가 나온다.
- 이미 낸 청구서는 낸 금액과 날짜만 보인다. VIEW_INVOICE만 있는 대리인과 보호자에게는 버튼이 없다.
- 대안 경로는 프런트 전화와 직원 대행이다. 입금과 방문 수납은 경리가 회원 대신 기록하고 직원은 카드 번호를 받지 않는다.
