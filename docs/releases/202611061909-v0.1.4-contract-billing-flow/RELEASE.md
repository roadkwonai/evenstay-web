# v0.1.4 — 계약·월 청구·수납 설계 흐름

기록 시각: 2026-11-06 19:09 KST

기존 계약·청구·수납 설계를 가상 사례 하나로 연결해 데이터 관계와 권한, 예외 처리의 이유를 빠르게 살펴볼 수 있도록 보완한다.

- 사업장·호실·계약 당사자·요금표·청구서·수납 관계와 사업장별 정책 버전을 정리한다.
- 발행 후 조정, 결제 결과 중복과 결과 미확인 시 확인·대사 절차를 기존 설계에 맞춰 설명한다.
- 보호자 열람 동의와 별도 대리권을 구분하고 현재 프로토타입과 향후 구축·운영 조건을 명시한다.
- 웹 아키텍처 페이지에 흐름과 상세 설계 연결을 추가한다. 실제 DB·API나 결제 서비스는 구현하지 않는다.

설계 보완분의 별도 승인 여부는 미정이다. 검증 결과는 `VERIFICATION.md`에 기록한다.
