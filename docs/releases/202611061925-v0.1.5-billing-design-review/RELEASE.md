# v0.1.5 — 계약·청구·수납 설계 판단 재검토

기록 시각: 2026-11-06 19:25 KST

계약부터 월 청구와 수납까지의 설계 판단을 재검토하고 한 흐름에서 확인하도록 보완한다.

- 계약·청구·수납의 상태 경계와 각 선택의 이유, 단계별 예외를 연결한다.
- 핵심 데이터 관계, 상태 전이, 권한, 다사업장, 외부 연동과 초기 범위를 찾아볼 수 있도록 기존 상세 근거와 연결한다.
- 향후 구현 시 검증할 조건과 제공자 규격·운영 정책의 미정 사항을 구분한다.
- 문서와 클릭형 프로토타입 범위를 유지하며, 설계 보완분의 승인 여부는 미정이다.
