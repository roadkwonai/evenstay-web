# v0.1.2 — 도식 도구 업데이트와 로컬 글꼴 검증

기록 시각: 2026-11-05 17:46 KST

Archify를 공식 3.2.0으로 올리고 로컬 Pretendard 글꼴의 검사 실패를 해결한다. 기존 아키텍처의 업무 규칙은 유지하며 새 도식 스키마에 맞춰 형식을 변환한다.

## 변경 내용

- 프로젝트 Archify를 3.0.1에서 3.2.0으로 업데이트하고 공식 릴리즈 커밋을 고정한다.
- 자동이체 상태 도식을 새 lifecycle 스키마로 변환하고 나머지 Archify 도식도 다시 생성·검증한다.
- diagram-design 검사기에 프로젝트 로컬 `--local-font` 옵션을 추가한다. 명시한 정확한 로컬 WOFF2 파일만 @font-face의 src에서 허용하며, 원격 URL·다른 경로·심볼릭 링크·비글꼴·임의 스크립트는 거부한다. 옵션 없는 기본 검사는 그대로 엄격하다.
- 문서용 도식 빌드에 자체 검사를 연결해 실패하면 PNG 생성 전에 중단한다. 검사 실패를 예외로 넘기던 절차를 없앤다.
- 회귀 테스트와 릴리즈 검사에 실제 글꼴 자체 검사를 추가하고 웹의 도식·버전·기록을 동기화한다.

- main에 별도 반영된 모바일 테마 호환과 소개 이미지 원본 링크 수정도 릴리즈 기준본에 포함된다.

## 호환성과 범위

업무 시스템이나 새로운 아키텍처 기능을 구현한 버전이 아니다. 기획 내용·모듈 경계·금전 및 의료 판단의 사람 경계는 유지한다. 기존 v0.1.1 기록과 태그는 보존한다. 프로젝트 로컬 검사기 수정은 업스트림 기본 기능과 구분해 출처 기록에 남긴다.
