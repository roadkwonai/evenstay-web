## 2. 조사 문서에서 고칠 점

허브가 토스 웹훅 문서를 직접 열어 대조했다.

- "토스는 서명 헤더가 없다"는 틀린 표현이다. 문서는 `tosspayments-webhook-signature`를 공통 헤더로 설명한다. 이벤트별 유무는 이 문서로 알 수 없다 [미확인].
- `secret` 비교를 적은 이벤트는 `DEPOSIT_CALLBACK`뿐이다.
- `PAYMENT_STATUS_CHANGED`에 `eventId`가 없는 것은 맞다.
- `transactionKey`+`orderId` 멱등 키는 문서가 권장한 값이 아니다. [가설]로 쓴다.

## 3. 반영하지 않는 것

| 항목 | 이유 |
|---|---|
| 앱 봉투 암호화로 좁히기 | 조사가 pgcrypto를 비교하지 않았다. 안심·가족 12절의 "[미정]"을 유지한다 |
| 동반자 타이머를 상태기계로 넣기 | 입법예고가 끝나지 않았고 법령 원본 대조 전이다. R10까지만 한다 |
| 평가 기반 변동 요금, 보증보험 상태 | 해외 사례 중심이고 이번 범위 밖이다. 조사 문서에 후보로 남긴다 |
| 비서 MCP 변경 | 조사 제안도 "유지"다 |
| 가족 대리인 역할 | 코어 권한 표에서 보호자와 대리인이 이미 다른 역할이다 |
