```
코어 MVP ─► G 최소판 ─► B ─► D MVP ─► G 정식 ─► C
                         │      ▲  │        ▲      ▲
                         └ 건강 소식 ┘  └ 고지·금전 인계 ┘ 케어 통지
```
- 모듈 순서 A → B → D → G → C [사실, 2026-11-02 확정]. B는 D보다 먼저 만들어지므로 B는 D가 없을 때 "보호자 알림을 보내지 않고 기록만"으로 동작하고, D가 붙으면 `HealthFeedCommand`로 올린다 [가설].
