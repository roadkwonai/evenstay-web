## 1. 포트폴리오 소개 (README, 면접 자료)
**제목**
> Evenstay 패밀리: 입주 회원이 정한 만큼만, 가족이 한곳에서 보는 보호자 화면

**부제**
> 회원이 가족마다 보여 줄 항목을 고릅니다. 거두면 다음 열람부터 바로 막히고, 누가 언제 무엇을 봤는지 모두 남습니다.

**문제** (한 단락)
> 멀리 사는 자녀는 부모의 소식을 시설, 병원, 방문요양에서 따로 듣고, 부모의 설명에 기대는 일이 많습니다. 회원은 자기 소식이 누구에게 얼마나 전해지는지 정할 방법이 없습니다. 가족과 건강정보를 나누려면 다른 동의와 따로 동의를 받아야 합니다. 생활 소식을 AI로 쓰려면 AI 기본법(2026-01-22 시행)에 따라 미리 알려야 합니다. 현장 직원은 통장을 맡아 달라는 부탁을 받아도 따를 기준이 없습니다.

근거: P-023, P-024(정보 분절), G14(민감정보 별도 동의), G4(AI 사전 고지. 보호자에게 나가는 글이라 내부 업무용 제외(G6)에 해당하지 않는다고 봄 [추정]), P-048·F25(금전 대행 기준 없음).

**무엇을 만들었나**
1. **가족마다, 항목마다 회원이 정하는 범위**
   생활 소식, 일정, 청구서, 건강 소식을 보호자마다 따로 허락합니다. 기본값은 "안 보여요"입니다. 직원이 대신 설정하면 회원이 확인한 다음에 적용됩니다.
2. **거두면 바로 막히고, 본 기록이 남는 열람**
   보호자가 화면을 열 때마다 권한을 다시 검사합니다. 허용된 열람과 막힌 열람이 모두 기록되고, 회원도 자기 소식을 본 기록을 봅니다.
3. **사람이 확인하는 AI와 정해진 금전 경계**
   생활 소식은 AI가 초안을 쓰고 직원이 고친 뒤 확인자 이름을 붙여 보냅니다. 직원이 통장·현금·이체 부탁을 받으면 직원이 할 수 있는 일과 넘길 곳이 화면에 나옵니다.

**설계에서 먼저 정한 것** (면접관용)
- 관계(누구인가) + 동의(무엇을 허락했나) + 역할(어떤 화면인가)을 하나의 정책으로 읽는다.
- 권한은 열람할 때마다 다시 계산한다. 그래서 철회가 다음 요청부터 반영된다.
- 알림 문자에는 내용과 링크를 넣지 않는다. 보호자가 Evenstay 패밀리를 직접 열면 권한 검사를 거친 화면에서만 내용이 보인다.
- 건강정보 별도 동의와 AI 사용 고지는 누가, 언제, 어느 버전 고지문에 동의했는지 데이터로 남긴다.

**CTA**
> 데모 열기

**데모 안내 문구**
> 회원 이은숙 님(A동 201호)과 함께 보실 분 두 명(딸 김지민, 아들 김태호)이 연결되어 있습니다. 딸에게는 생활 소식, 청구서, 건강 소식을, 아들에게는 생활 소식만 보여 주도록 정해 보세요.

### 2-5. 직원이 대신 정했을 때 회원 확인
직원이 태블릿에서 회원의 말을 듣고 보여 주기를 입력하면 `입주자 확인 대기` 상태가 된다. 회원이 확인하기 전에는 보호자에게 보이지 않는다. **그만 보여 주기는 반대로 직원 입력만으로 바로 적용한다.** 보이는 범위를 좁히는 쪽은 기다리게 하지 않는다(전화로 급히 거두고 싶은 회원을 위해).

| 위치 | 문구 |
|---|---|
| 화면 제목 | 직원이 적은 내용이 맞는지 봐 주세요 |
| 본문 | 최민수 직원이 회원님 말씀을 듣고 아래처럼 적었어요. 맞으면 [맞아요]를 눌러 주세요. 확인하시기 전에는 아무에게도 보이지 않아요. |
| 요약 | 김지민 님(딸): 생활 소식, 청구서, 건강 소식 · 김태호 님(아들): 생활 소식 |
| 건강 소식이 들어 있을 때 | 건강 소식은 따로 동의가 필요해요. 다음 화면에서 한 번 더 여쭤볼게요. |
| 버튼 | [맞아요] [고칠게요] |
| 확인 후 | 확인하셨어요. 지금부터 정하신 대로 보여요. |
| 고칠게요를 누른 뒤 | 직원에게 다시 말씀해 주시거나, 이 화면에서 직접 바꾸셔도 돼요. |
| 직원이 "그만 보여 주기"를 대신 입력했을 때 (회원 화면) | 최민수 직원이 회원님 말씀대로 김태호 님(아들)께 생활 소식이 안 보이도록 바꿨어요. 맞지 않으면 프런트에 말씀해 주세요. |
| 직원 입력 화면 안내 (직원이 보는 문구) | 입주자 확인 전에는 보호자에게 보이지 않습니다. 입주자가 화면을 직접 읽고 [맞아요]를 누르도록 태블릿을 건네주세요. |

### 2-6. 대신 처리하실 분이 정했을 때
판단이 어려운 회원의 경우, "보호자 열람 권한 관리" 권한이 있는 대리인(코어 2-4)이 정한다. 대리인이 있어도 회원은 그만 보여 주기를 언제든 직접 할 수 있고(즉시 적용), 더 보여 주는 것은 대리인이 정한다(prd 확인할 것 10, 2026-11-03 확정). 아래 최○○ 님은 이 권한이 있는 대리인의 예시다. 데모의 김태호 님은 이 권한이 없다(6절 "대리인 권한 밖 설정").

| 위치 | 문구 |
|---|---|
| 회원 화면 상단 | 대신 처리하실 분 최○○ 님이 보여 줄 것을 정했어요. |
| 회원 화면 상단 아래 | 그만 보여 주기는 회원님이 직접 하실 수 있어요. 더 보여 주시려면 프런트에 말씀해 주세요. 최○○ 님께 전해 드려요. |
| 대리인 화면 상단 | 이은숙 회원님 대신 정하실 수 있는 일: 보호자 열람 권한 관리 |
| 대리인 화면 안내 | 회원님이 전에 하셨던 말씀과 뜻을 먼저 헤아려 정해 주세요. 정하신 내용은 회원님 화면에도 보여요. |

### 2-9. 건강 소식에서 뺀 일 (회원 화면)
회원이나 대신 처리하실 분이 "이 일은 가족에게 보이지 않게 해 달라"고 하면 직원이 그 일을 건강 소식에서 뺀다(`MEMBER_REQUEST`. 들은 직원과 시각을 남긴다). 이미 보이던 소식도 뺄 수 있다. 회원 화면에는 뺀 사실이 보인다. 건강과 무관한 신호(다른 회원의 신호, 같은 신호가 두 번 온 것, 기기 시험)는 처음부터 건강 소식이 아니므로 회원 화면에도 보이지 않는다.

| 위치 | 문구 |
|---|---|
| 회원 요청으로 뺐을 때 | 11월 12일 새벽에 직원이 방에 다녀간 일을 회원님 말씀대로 건강 소식에서 뺐어요. 함께 보실 분께 보이지 않아요. (처리: 김하진 직원) |
| 대신 처리하실 분 요청으로 뺐을 때 | 11월 12일 새벽에 직원이 방에 다녀간 일을 대신 처리하실 분 최○○ 님 요청으로 건강 소식에서 뺐어요. 함께 보실 분께 보이지 않아요. (처리: 김하진 직원) |
| 아래 안내 | 잘못 뺀 것 같으면 프런트에 말씀해 주세요. [미정: 뺀 소식을 다시 올리는 방법은 기획에서 확정] |

### 2-10. 생활 소식에 자리를 비우신 날이 더해질 때 (이미 보여 주신 회원) — [법률 검토]
장기 부재 소식(F18)이 생기기 전에 생활 소식을 누군가에게 보여 주기로 한 회원에게, 그 뒤 처음 들어올 때 한 번 보인다 [가설]. 대신 처리하실 분이 열람 범위를 정하는 회원이면 그분에게도 같은 화면이 보인다 [가설]. 이 안내를 확인하기 전에 부재 소식을 보낼지는 정하지 않았다 [미정: D 기획].

## 3. AI 사용 사전 고지
AI 기본법(2026-01-22 시행)은 생성형 AI를 쓰는 제품·서비스를 제공할 때 이용자에게 미리 알리게 한다(제31조. G4). 고지할 때 이용자 연령을 고려하라는 시행령안 내용이 있다(G6). 회원과 보호자 모두 처음 쓸 때 한 번 보이고, [AI 사용 안내] 메뉴에서 언제든 다시 볼 수 있다. 회원 화면 "AI 사용 안내" 메뉴는 이 콘솔(I-42)이 보관한다.

Evenstay에서 AI를 쓰는 곳은 두 곳이고, 쓰는 방식이 다르다. 고지는 이 차이가 보이게 두 덩어리로 나눈다.
| | 생활 소식 (D) | Evenstay 홈 비서 (G) |
|---|---|---|
| AI가 하는 일 | 매주 생활 소식을 먼저 쓴다 | 말로 물은 질문이 무엇인지 알아듣는다. 답은 AI가 쓰지 않고, 서버가 입주 계약과 청구서 기록을 정해진 틀에 채워 바로 보인다. 큰 버튼은 AI를 쓰지 않는다(G ADR-G1) |
| 직원 확인 | 직원이 읽고 고친 뒤에만 나간다 | 직원이 미리 읽지 않는다 |
| 판단이 필요한 일 | AI가 판단하지 않는다(건강, 돈, 계약은 직원이 처리) | 건강, 돈, 계약과 볼 수 없는 기록은 답하지 않고, 회원이 [네, 전해 주세요]를 누르면 직원에게 넘긴다 |
| 표시 | 확인한 직원과 날짜(3-4) | 답마다 "AI 비서", 답 끝 "확인한 곳"(3-4) |

- 고지문 버전: **v2(2026-11-03, 비서 추가)**. v1(생활 소식만)을 읽은 회원에게는 다음 접속 때 v2를 다시 보인다(5-5 "고지문 개정 안내"). 비서는 첫 사용 전에 이 고지를 보인다. 2026-11-03 비서 문구를 G ADR-G1에 맞춰 고쳤다. v2는 아직 회원에게 보인 적 없는 초안이라 버전을 올리지 않고 v2 안에서 고쳤다. 확정(2026-11-03).

>    나. 비서: 회원이 버튼으로 고르거나 말로 물은 질문, 입주 계약 일정, 청구서 기록. 말로 물은 음성은 저장하지 않고 글자로 바뀐 말만 남습니다. [NEED: 음성을 글자로 바꾸는 방식과 처리 위탁 여부 — G 기획 미정, 법률 검토] 대화 기록과 조회 기록은 보관되며, 담당 직원이 열람할 수 있고 열람한 직원과 시각이 기록됩니다. 대화 중 회원이 말한 건강 관련 내용도 대화 기록에 남을 수 있습니다. 대화 원문(회원이 한 말, 비서의 답, 직원에게 전한 말)은 대화가 끝난 날부터 1년이 지나면 지우고, 이용 횟수 같은 숫자만 남깁니다 [운영사 기준 초안, 법률 검토]. 조회 기록과 열람 기록의 보관 기간: [NEED: 코어 감사 기록 보존 정책]

## 4. 보호자 화면 (Evenstay 패밀리)
해요체. 볼 수 있는 것과 없는 것을 먼저 보인다. 볼 수 없는 이유는 회원의 결정이라는 것만 말하고, 회원에게 요청하라고 부추기지 않는다.

### 4-3. 볼 수 있는 범위가 넓어졌을 때와 좁아졌을 때
| 위치 | 문구 |
|---|---|
| 알림 문자 (넓어졌을 때만, 내용 없이) | [Evenstay 패밀리] 이은숙 회원님 소식에서 볼 수 있는 것이 늘었어요. Evenstay 패밀리에서 확인하실 수 있어요. |

| 좁아졌을 때 | (문자 없음, 따로 알리는 문구 없음) "볼 수 있는 것" 목록이 바로 바뀌고, 열려 있던 화면은 6절 "허락되지 않은 항목을 열 때" 문구가 나온다. |
| 새 소식 알림 문자 (건강 소식 포함, 모든 항목 같음) | [Evenstay 패밀리] 이은숙 회원님의 새 소식이 있어요. Evenstay 패밀리에서 보시거나 프런트 02-000-0000 (가상 번호)로 전화 주세요. |

- 범위 문자는 넓어질 때만 보낸다 [가설: 운영값, 2026-11-03 사용자 확정. D tech-design `SCOPE_WIDENED`]. 좁아질 때 알리지 않는 것은 회원이 거둔 사실이 알림으로 드러나지 않게 하기 위해서다. 보호자 화면이 못 보는 이유를 구분하지 않는 원칙과 같다. 넓어질 때도 무엇이 늘었는지, 누가 바꿨는지는 문자에 쓰지 않는다.
- 문자를 보내기 전에 범위가 다시 좁아지면 보내지 않는다(보낼 때 권한을 다시 검사).
- 알림 문자에는 내용(금액, 건강 소식)과 "건강"이라는 말을 넣지 않는다. 그래야 그만 보여 주기가 문자에도 적용되고, 잠금 화면에 건강 이야기가 뜨지 않는다.
- 새 소식 문자와 범위가 넓어졌다는 문자는 조용한 시간(밤 10시~아침 8시)에는 보내지 않고 아침 8시에 보낸다 [가설: 운영값, 2026-11-03 사용자 확정].
- 알림 문자에 링크를 넣지 않는다. 링크를 누르게 하는 문자는 사칭 문자와 구분하기 어렵다(P-039). B 카피 3절이 사칭 문자와 구분하려고 정한 원칙(다른 앱 설치나 결제를 요구하지 않음)을 한 걸음 더 적용했다. 보호자는 자기 휴대전화의 Evenstay 패밀리를 직접 열거나 프런트에 전화한다. 처음 초대 문자(2-2)만 링크를 쓴다.

## 8. 교정 기록 (`copy-editing` 7회 검토)
처음부터 원칙(회원 해요체, 직원 합쇼체, 효과 수치 없음, 대안 경로, 결정은 회원에게)을 적용해 썼다. 아래는 초안을 다시 읽으며 **실제로 발견하고 고친 것**만 적었다.

| 검토 | 확인한 것 | 결과 |
|---|---|---|
