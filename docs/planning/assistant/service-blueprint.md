## 읽어 낸 것
- 백스테이지가 몰린 곳은 **도구 호출 한 번**(대상 회원 고정 → 권한 검사 → 호출 → 기록 → 답 틀)이다. 이것을 도구 등록부 한 곳에서 처리하면 B·D·C 도구가 붙어도 흐름 2·3이 바뀌지 않는다.
- 상태를 바꾸는 지점은 두 곳(청구 문의, 넘김)뿐이고 둘 다 확인 토큰 하나로 묶인다. 사람이 판단하는 지점(회원 [네], 직원 처리, 경리 답변)은 모두 "누가, 언제"를 남긴다.
- LLM이 들어오는 곳은 흐름 3-2 하나다. 큰 버튼 흐름(2)은 LLM 없이 끝난다. 그래서 LLM이 멈춰도 핵심 흐름은 돈다(카피 6절 [가설]을 확정, `prd.md` 확인할 것 8 [가설]).
- 기술로 막을 수 없는 것(넘긴 요청을 늦게 봄 X7, 직원의 호기심 열람 X10)은 기록과 확인으로만 줄인다. 면접에서 한계로 밝힌다.
