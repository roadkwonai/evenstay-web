| **Staylane** | 스테이레인 | stay + lane(길). 입주 → 거주 → 단계 전환 → 퇴거로 이어지는 계약의 길, 상태 전이 설계와 맞다 | 운영 | 없음 |
| **Keystay** | 키스테이 | key(열쇠·출입·계약) + stay | 운영 | Key2stay(스위스 단기숙박), KINSTAY(국내 호텔)와 비슷 |

| Hearthly | 허슬리 | hearth(집의 중심) + -ly | 운영 | Hearth 회사 2곳. 한글 읽기가 hustle처럼 들린다 |
| Tendwell | 텐드웰 | tend(돌보다) + well | 회원 | 시니어 돌봄 소프트웨어 Tendly와 비슷 |
| Hearthkey | 허스키 | hearth + key | 운영 | 한글 읽기가 "허스키"(개 품종)와 같아 오해 소지 |
| Oakhaven | 오크헤이븐 | oak(튼튼함) + haven(안식처) | — | 같은 이름 미발견. 다만 "-haven"은 해외 시설 이름에 흔해 소프트웨어보다 시설 이름처럼 들린다 |

**v3 변경(2026-11-03)**: 직원 화면 열의 모듈 이름을 한글로 바꿨다. Evenstay Safety → 안심 알림, Evenstay Family Admin → 보호자 포털·동의, Evenstay Assistant Admin → AI 생활 비서, Evenstay Transitions → 생활 지원 단계. 이유: 사용자 결정(2026-11-03). 회원·보호자 브랜드(Evenstay, Evenstay Home, Evenstay Family)와 slug, 코드·폴더 이름(safety/, family/ 등)은 그대로 둔다.

**모듈 추가(2026-11-04, 허브 요청)**: 모듈 표에 N1 생활 요청과 N2 커뮤니티 줄을 더했다. 이름은 각 모듈 카피가 정한 그대로다(`senior-lab/03-copywriting/ideas/life-requests/names.md` 1절 "정한 것", 2026-11-03 / `senior-lab/03-copywriting/ideas/community/names.md` 1절 "정한 것", 2026-11-04). 이 표는 회원·보호자 열이 하나라서, 보호자 화면이 다른 N2는 "회원:"과 "보호자:"로 나눠 적었다.
