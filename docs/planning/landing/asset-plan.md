**영상 모델:** MiniMax H3(`minimax_h3`)로 확정했다 [사실: 사용자 "영상모델도 MiniMax H3 로 확정했어", 2026-11-04]. 8편(VID-LOUNGE, VID-H1~H4, VID-T1·T2, VID-SAFE-VISIT)을 H3로 만들고, 이미 만든 VID-BLDG, VID-ROOM 2편은 Kling 4.0 파일을 그대로 쓴다 [사실: `shared/decisions.md`]. 5초 16:9 한 편이 10크레딧(2K)이고, Kling 4.0은 720p 11.25크레딧, 1080p 16.25크레딧이다 [사실: `higgsfield generate cost` 조회, 2026-11-04]. 길이는 4~15초이고 화면비는 16:9와 4:3을 고를 수 있다 [사실: `higgsfield model get`]. VID-H1 비교 시험 1건에서 얼굴 유지는 Kling과 같았다 [사실: `shared/decisions.md`]. 비교에 쓴 `vid-h1-kling.mp4`는 쓰지 않는다.

**`gpt-image-api` 참조와 크기:** 참조는 최대 16장이고 크기는 16:9 1536x864, 4:3 1536x1152, 4:5 1024x1280이 된다 [사실: 공식 문서 기준, 허브 전달 2026-11-04]. 실제 호출로 확인한 것은 16:9, 4:3, 2:1 2048x1024와 참조 2장까지다 [사실: `evenstay/design/site/assets/prompts.md`]. 4:5와 참조 3장 이상은 아직 시험하지 않았다 [미확인]. 이 문서의 참조는 최대 7장이다(IMG-DINE, IMG-LIFE-EXER).

디자인 단계에서 먼저 확인할 것 [미확인]:
- `gpt-image-api` 참조 3장 이상과 4:5 1024x1280이 실제 호출에서 되는지(1건 시험). `gpt-image` 스킬의 참조 장수와 크기.
- `soul-id`는 Soul 계열 이미지 모델에만 쓸 수 있어 sunburst와 영상 모델에 맞지 않아 보류했다 [사실: `shared/decisions.md` 2026-11-04].
- MiniMax H3에는 소리를 끄는 옵션이 보이지 않아 받은 영상에서 소리 트랙을 뺀다 [사실: `prompts.md`].

## 10. 생성 순서
키 이미지가 확정되기 전에는 나머지를 만들지 않는다 [사실: 허브 지시]. **1~4단계는 끝났다: 키 이미지 15장 확정(2026-11-04)** [사실: `shared/decisions.md`]. 다음은 5단계다. 1~4단계가 키, 5~6단계가 1단계(메인), 7~8단계가 2단계(페이지)다(U-04). 각 단계 끝에 사용자 확인이 있다. 다시 만들기 상한은 U-05.
