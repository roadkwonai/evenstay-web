# 축 10 출처: 시니어 금융 자산관리 서비스 시장

조사일: 2026-11-02 · 기존 출처 F1~F29는 `axis8-senior-finance.md`, D/A/E는 기존 축 파일. 여기서는 K 번호를 쓴다.

확인 표기
- **대조함**: 원문 페이지(기사, 공식 안내, 회사 페이지)를 직접 열어 해당 내용을 확인했다. 기사 한 건만 본 것은 비고에 "단일 기사"로 적었다.
- **요약만**: 검색 결과 요약만 봤고 원문을 열지 못했다. 노트에서는 [요약만]으로 표시한다.
- 회사 페이지·보도는 "회사 주장"으로 표시했다. 블로그(algolab 등)는 법적·약관 근거가 아니다.
- 법령 조문(금융소비자보호법 제17조·제18조 등)은 law.go.kr에서 본문이 열리지 않아 모두 [미확인-원문 재확인 필요]다. 한국예탁결제원·금융위 보도자료 원본(PDF/HWP)과 KIS·NH·키움 이용약관 본문도 열지 못했다.
