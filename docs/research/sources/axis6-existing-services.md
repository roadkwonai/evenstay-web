# 리서치 축 6 출처: 기존 시니어 서비스와 빈틈

조사일: 2026-11-02 · 방법: WebSearch + WebFetch.
**확인 수준 정의**
- **대조함** = 원문 페이지를 직접 열어(WebFetch) 해당 수치·날짜를 확인했다. 단, WebFetch는 소형 모델이 본문을 요약해 돌려주는 방식이라 "원문 한 글자까지 대조"는 아니다.
- **요약만** = 검색 결과 요약에서만 봤다. 본문 미열람. 수치는 인용만 하고 확정하지 않는다.
- 법령 원문(law.go.kr)은 열었으나 본문이 비어 있었다(조문 미확인). 시행일은 복지부 보도자료(E1)로 대조했다.
- 회사·정부 홍보 수치는 "주장"으로 표시한다.
