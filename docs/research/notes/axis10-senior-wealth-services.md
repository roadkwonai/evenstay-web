## 0. 핵심 발견
1. [사실] 한국투자증권은 제3자에게 서비스를 제공하는 법인 제휴를 **투자일임업·투자자문업을 하는 제도권 금융회사로 한정**하고 핀테크는 제휴 불가라고 안내한다(K25). [추정] 비금융 사업자인 시니어하우징 운영사가 입주자 계좌에 직접 연결하는 정식 경로는 이 증권사에는 없다. NH(Namuh PLUG)·키움·LS의 B2B 제휴 구조와 약관은 확인하지 못했다.
2. [사실] 2026년 하반기에 NH(8-10), KB(7-20 오픈베타), 토스(8-13 정식)가 개인용 오픈API를 열었고, 토스는 사용자가 발급 키를 ChatGPT·Claude에 연결해 자연어로 조회·주문하는 방법을 소개한다(K30, F26, K29). [추정] 증권사가 "본인 키 + 외부 LLM"을 이미 공식 용도로 보는 방향이라 L1의 기술 기반은 흔해지고 있다.
3. [사실] "LLM 설명 + 증권 API + 자동매매"를 사업자가 다수 고객에게 제공하는 서비스는 찾지 못했다. 가장 가까운 것은 카카오페이증권의 "1인 1 AI 투자 에이전트" 구상(2026-07-23, 라이선스 언급 없음, 출시 미확인)과 코스콤 테스트베드를 거치는 로보어드바이저(계약자 37.5만명, 1.17조원)다(K23, K22). 로보어드바이저는 자문·일임 등록 업자가 알고리즘을 심사받는 구조다 [사실, 등록 요건 상세는 미확인].
4. [사실] 고령 투자자 보호는 65세 이상, 고난도·파생 상품의 녹취·숙려, 2025-07 적합성 평가 강화안(예고)까지 확인된다(K9, K8). 자동매매·알고리즘에 고령자를 따로 적용하는 규정은 찾지 못했다 [미확인]. 거래소에서 투자자가 직접 하는 매매는 녹취·숙려 대상에서 제외된다는 요약이 있다(K9, 요약만).
5. [사실] 해외 가족 공동 관리 서비스(EverSafe, True Link, Carefull)는 "이체하지 않는 모니터링 + 신뢰 대리인 알림"(EverSafe) 또는 "한도·가맹점 제한 카드"(True Link)이고, Carefull은 금융기관을 통한 B2B2C로 간다(K32~K34). [사실] 한국의 비교 가능한 제도는 2019년 지정인 알림이고 은행 예금·이체는 대상이 아니었다(F14).

## 7. 시니어하우징 접점과 이해상충

- [사실] 입주자 대상 금융 서비스를 하우징 운영사가 직접 제공하는 해외 사례는 이번 검색에서 찾지 못했다 [미확인]. 찾은 것은 CCRC 소비자 위험 자료(환불 지연, 월 비용 인상, 상위 케어 이전 판단의 이해상충)뿐이다(K36, 2010 자료).
- [사실] 일본에서는 케어 서비스 업체가 은행·증권사와 제휴해 고객을 소개하는 사례가 있다는 2차 보도가 있으나 시니어 주택 운영사인지 확인되지 않았다(K37, 요약만).
- [추정] 이해상충 지점: 운영사는 보증금·월 비용의 수취인이다. 입주자 자산을 기준으로 상품을 권유하거나, 계좌 정보를 운영사가 보면 가격·퇴거 판단에 쓰일 우려가 생긴다(F-10 참조). 허용 방향은 축 8의 6-2와 같다: 청구 설명, 본인·보호자 열람, 외부 전문가 연결.
- [사실] [지원 회사]는 시설 소유주 대신 운영·자문하는 구조라 입주자와의 계약 상대가 소유주와 운영사로 갈릴 수 있다(K20). 책임 소재는 [미확인].
