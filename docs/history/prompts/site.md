허브 요청(범위 추가): 랜딩 한 장이 아니라 Evenstay 소개 사이트로 범위를 넓혀 주세요. 지금 쓰고 있는 문서에 이어서 반영하면 돼요.
사용자 말(그대로): "현재 프로토타입에 evenstay 직원, 센터장, 오시는길, 시설사진, 전경사진, 숙소사진 등등 이런 부분들이 빠진거같은데", "Evenstay 소개 페이지, 시설 소개 등등도 모두 빠져 있는 것 같아".

할 일:
1. `prd.md`에 사이트맵(정보 구조)을 넣어요. 메인 랜딩은 지금 설계 그대로 두고, 아래 페이지를 추가해요. 첫 판과 다음 판을 나눠 적어요.
   - Evenstay 소개: 브랜드 이야기, 센터장 인사, 직원 소개(역할별)
   - 시설 소개: 건물 전경, 공용 공간(라운지, 식당, 정원, 도서 공간 등), 안전·편의 설비 소개(판단 단어 없이)
   - 숙소 안내: 숙소 유형별 실내 사진과 구성(평면 일러스트 포함 가능). 면적·가격은 [미정], 지어내지 않음
   - 생활·서비스: 하루 일과, 식사, 여가 프로그램, Evenstay 홈·패밀리 앱 소개
   - 오시는 길: 가상 주소, 일러스트 약도, 교통 안내(가상)
   - 입주 상담: 상담 신청·전화·방문 예약 안내, 자주 묻는 질문
   - 그 밖에 시니어 레지던스 소개 사이트에 흔히 있는 페이지가 있으면 후보로 적고 이유를 붙여요
2. `screen-spec.md`에 페이지마다 화면 ID(예: SITE-ABOUT-01)와 섹션을 메인 랜딩과 같은 형식으로 추가해요.
3. `asset-plan.md`에 새 에셋을 더해요: 센터장 1명, 역할별 직원, 건물 전경(낮·저녁 등), 공용 공간, 숙소 유형별 실내, 약도 일러스트 등. 영상으로 만들면 좋은 장면은 표시하고, 에셋 총계와 늘어난 양을 따로 적어요(생성 비용이 들어 사용자가 개수를 승인해요).

지킬 것(앞 요청에 더해):
