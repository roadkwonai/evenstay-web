# 프로토타입 문구·흐름 검수 기록

## 3. 새로 쓴 문구와 지어낸 값

이 절의 값은 모두 가상이고 기획 문서에 없다. 문구는 카피 세션, 값은 기획이 정해 주면 바꾼다. 문서와 어긋난 점의 결정은 허브가 사용자에게 받는다.

### ②단계(41장면)


대조 방법: 모듈 보고 7개와 qa-a/b/c에 적힌 항목을 `strings/*.json`, `data/*.json`에서 찾아 지금 키와 값을 적었다. 문구는 `docs/` 전체와 `design/canvas-notes.md`, `design/mvp-screens.md`에서 문장 단위로 찾아, 없는 것만 "새 문구"로 봤다. 캔버스 보드 원본은 저장소에 없어 보드에서 온 문구는 가려내지 못했다. 다른 세션이 계속 고치고 있어 키는 읽은 시점 기준이다. 코드, strings, data, 기획 문서는 건드리지 않았다.
