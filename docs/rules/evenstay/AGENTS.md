# 다른 AI와 함께 작업하는 지침 (evenstay)

ChatGPT, Codex, Gemini처럼 Claude Code가 아닌 AI가 읽는 문서다. 공통 지침은 `senior-lab/AGENTS.md`에 있다. 진행 상황을 확인하는 순서, 검토 항목, 수정 권한, 고치는 위치, 아키텍처 페이지 제작, 설치하고 사용한 스킬을 그 문서에서 먼저 본다.

이 저장소의 규칙은 `CLAUDE.md`, 전체 그림은 `docs/project.md`, 용어는 `docs/glossary.md`다. git 저장소가 아니므로 덮어쓰면 되돌릴 수 없다. 검토 결과는 원본을 고치지 말고 senior-lab `00-hub/reviews/`에 남긴다.
