# 05-portfolio: 케이스 스터디 · 발표자료 · 이력서

목적: 완성된 MVP를 지원 회사의 관점에 맞춘 포트폴리오로 정리한다. MVP가 하나 이상 나온 뒤 시작한다.

## 입력
- `../shared/target-companies.md` (어떤 회사에 무엇을 강조할지)
- `../04-planning/ideas/<slug>/` 기획 문서
- MVP 결과: 배포 URL, 스크린샷, 데모 영상, 저장소 링크 (``, 모듈은 하위 폴더)
- 리서치 근거: `../01-research/outputs/problem-bank.md`

## 사용할 스킬
| 스킬 | 위치 | 하는 일 |
|---|---|---|
| `case-study` | 로컬 | 문제 → 리서치 → 선택과 포기 → 설계 → 결과 → 배운 점 구조의 케이스 스터디 |
| `presentation-deck` | 로컬 | 면접용 발표자료 구성 |
| `review-resume` | 로컬 | 이력서와 경력기술서를 지원 포지션에 맞춰 점검 |
| `make-pdf`, `anthropic-skills:pptx` | 전역 | 최종 PDF·PPTX 출력 |

## 원칙
- 회사별로 강조점을 바꾼다. 같은 MVP라도 운영 효율, 입주자 경험, 신사업 중 회사의 관심사에 맞춘다.
- 실제로 하지 않은 사용자 검증이나 성과 수치를 쓰지 않는다. "가설", "데모 기준"으로 표현한다.
- 리서치 근거(출처)를 케이스 스터디에 남겨 문제 정의의 설득력을 보여준다.

## 산출물
- `drafts/`: 작업본
- `outputs/<company>/`: 회사별 케이스 스터디, 발표자료, 이력서 점검 결과
