# v0.1.2 검증 기록

검증일: 2026-11-05(KST).

## 업데이트와 호환성

- 프로젝트 Archify 3.2.0, 공식 커밋 `208acba8d412335185b2056fedf54b3405df43fb`를 확인했다. 별도 전역 설치본을 갱신한 것은 아니다.
- 업데이트 도구의 백업·소스 대조 뒤 환경 진단, 잠금 파일 기반 개발 의존성 설치(설치 스크립트 실행 안 함), 생성된 검증기 일치 검사와 CLI 구문 검사를 통과했다. setup 상태도 실제 검증 근거로 complete 처리하고 current를 재확인했다.
- Archify 5장의 validate, deliver, strict check, browser-check가 전부 통과했다.
- 자동이체 도식을 lifecycle v3로 변환했다. 이전 후보와 상태 11개, 전이 10개 및 설명 카드의 문구를 대조해 보존했다. 새 크기에 맞춰 PNG·iframe 높이를 맞췄다.

## 로컬 글꼴 검사

- 원인은 CSS의 모든 non-fragment url을 거부하는 검사 정책이었다.
- 프로젝트 로컬 검사기에 `--local-font`를 추가했다. 정확히 지정한 상대경로의 일반 WOFF2 파일만 @font-face src에서 허용하며 경로·심볼릭 링크·확장자·WOFF2 서명을 확인한다. 옵션을 주지 않으면 기존 엄격 정책을 유지한다.
- 업스트림을 갱신한 것처럼 표시하지 않고 로컬 패치와 원래 파일 해시를 설치 기록에 남겼다.
- 회귀 테스트 5개 통과: 정상 로컬 글꼴, 기본 거부, 원격·다른 경로·누락·비글꼴·data URL 거부, 심볼릭 링크와 일반 CSS 배경 URL 거부, import·임의 스크립트 거부.
- 문서용 도식 6장의 자체 검사가 모두 종료 0이다. 기존 실패를 무시하는 예외는 사용하지 않았다. 빌드가 자체 검사 실패 시 PNG 생성 전에 중단한다.
- 독립 읽기 전용 검토에서 검사 범위의 불필요한 완화를 발견하지 못했다.

## 웹·생성물

- 실제 Chrome에서 도식 16개가 열리고 Pretendard가 loaded 상태임을 확인했다. SVG·텍스트 누락과 콘솔 오류는 0건이다.
- 아키텍처·릴리즈 목록·0.1.2 기록을 1440px·375px에서 확인했다. 6건의 버전·HTTP·콘솔·가로 넘침 검사가 통과했다.
- 핵심 흐름 탭 4개를 두 폭에서 눌러 iframe 안의 SVG·글꼴 로딩 완료를 기다리고 표시를 확인했다. 결제·에이전트·문서 PNG와 모바일 결제 도식을 확대 확인했다.
- 릴리즈 자체 검사에서 세 폴더 버전 0.1.2, 릴리즈 기록 3개, 도식 16장 HTML·PNG 공개 사본 일치와 실제 글꼴 자체 검사 통과를 확인했다.
- 문구 검사 누락·미사용·금지어·코드 내 한글 0건, 아키텍처 용어 검사 17파일·94규칙 발견 0건.
- sloplint FAIL 0. 이번에 바꾸지 않은 공통 CSS에 WARN 6개·REFLEX 1개가 보고돼 별도로 남긴다. 이를 통과나 수정 완료로 바꾸지 않았다.
- 전체 프로토타입 업무 흐름이나 모든 문서의 링크를 이번에 다시 검사하지는 않았다. 범위는 도구 업데이트·도식·글꼴·릴리즈 연결이다.

## 배포와 한계

GitHub Release와 Pages의 실제 게시 결과는 게시 후 DEPLOYMENT.json으로 남긴다. 기존 v0.1.1 태그와 릴리즈는 변경하지 않는다. 실제 운영·현장 설비·은행·클라우드·법률 적용 시험은 범위 밖이다. 별도 세션에서 main에 반영한 모바일 테마 호환·소개 이미지 링크 변경은 보존한다.
