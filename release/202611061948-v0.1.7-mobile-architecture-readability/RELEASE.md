# v0.1.7 — 모바일 아키텍처 가독성

기록 시각: 2026-11-06 19:48 KST

핵심 데이터 관계와 계약·청구·수납 흐름을 모바일에서도 읽기 쉽게 보완한다.

- 축약 ERD와 관계 설명을 좁은 화면에서 살펴볼 수 있도록 구성한다.
- 계약에서 청구 발행, 자동이체 수납까지의 흐름과 예외를 모바일 읽기 순서에 맞춘다.
- 기존 설계안과 전체 도식, 상세 문서 연결을 유지한다. 실제 데이터나 결제는 구현하지 않는다.

검증 결과는 `VERIFICATION.md`에 기록한다.
