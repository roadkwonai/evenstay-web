# v0.1.7 검증 기록

- 모바일 관계 설명을 데스크톱 관계표와 같은 7개 원본 행에서 만들고 계약·청구·수납 3단계의 읽기 순서를 확인했다.
- Chrome 320·375·390·1440px, 밝은·어두운 테마와 100·200% 글자 확대를 확인했다. 페이지와 주요 내용의 가로 넘침은 없었다.
- 예외 링크의 키보드 진입과 원본 도식 링크, 단계별 내용 및 모바일 관계 7개를 확인했다.
- 문구·용어 검사, sloplint, 공개본 동기화 검사를 수행했다.
- 실제 휴대전화와 스크린리더는 확인하지 않았다. 도식과 흐름은 구현 전 설계안이다.
