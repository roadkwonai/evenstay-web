# v0.1.5 검증 기록

- 코어 설계 2·3·6·9절과 계약 체결 시 요금표 버전, 청구 발행, 자동이체 배치·예상 수납·확정 수납 및 권한을 독립 대조했다.
- 핵심 관계·상태 전이·권한·다사업장·외부 연동·초기 범위 6개 항목과 각 상세 근거를 연결했다. 향후 구현 검증 조건은 수행 결과와 구분했다.
- Chrome 1440px·375px에서 밝은·어두운 화면, 주제 앵커 6개, 상세 링크 10개, 수납 도식, 표 키보드 포커스, 가로 넘침과 JavaScript 오류를 확인했다.
- 웹 생성, 문구·용어 검사와 sloplint FAIL·WARN·REFLEX 0을 확인했다.
- 실제 제공자 규격, 현장 정책, 실기기와 보조공학 도구는 확인하지 않았다. 본 문서는 가상 사례를 이용한 구현 전 설계안이다.
