# v0.1.3 검증 기록

검증일: 2026-11-05(KST). 대상은 공통 CSS의 기존 sloplint WARN 6건·REFLEX 1건과 검증 중 발견한 상단 영역의 기존 결함이다.

## 원인과 수정

- 서체 수 검사기는 `--font-weight-*`의 700·600·400·500을 서체 이름으로 세고 있었다. 프로젝트 로컬 검사기가 서체 값과 타이포그래피 수치를 구분하도록 수정했다. 실제 4개 서체 선언 검사는 유지한다.
- 표면 6곳은 배경만 소유하고 글자색을 부모에게서 상속했다. 기본 화면의 대비 부족을 확인한 것은 아니며, 부모를 상태색으로 바꾸면 일반 본문도 그 색을 물려받는 경우를 회귀 검사로 재현했다. 기존 `--fg-default`를 명시해 이 누수를 막았다.
- `DESIGN.md`와 생성 토큰 원본의 해시는 수정 전 보관본과 같다. 색·서체·크기·배치를 새로 설계하지 않았다.
- 상단 영역 검사에서 처음 발견한 실패 7건은 수정 전 CSS를 요청 가로채기로 주입해도 동일했다. 홈·소개 사이트는 실제 막대 높이가 없어 권한창이 막대와 28~36px 겹쳤고, 앱은 1280px에서 테마 버튼이 추가된 뒤 두 줄이 됐다.
- 홈·소개 사이트의 안정된 상단 요소만 ResizeObserver로 관찰한다. 앱의 기존 측정은 유지해 재렌더 중 분리된 요소의 0px 높이를 기록하지 않도록 했다. 앱의 중간 폭은 중복 마크를 접고 기존 기능을 유지하며 여백을 압축하고 아이콘 테마 버튼을 44×44px 이상으로 보장했다.

## 시각·독립 검토

- 홈의 밝은·어두운 테마를 1440px·375px에서 캡처하고 모바일 권한창과 1280px 앱 막대를 확인했다. 전환 애니메이션이 끝난 권한창은 불투명한 배경으로 막대 아래에 표시됐다.
- 독립 검토에서 6개 표면의 전경색 계약과 서체 검사 수정의 타당성을 확인했다. 추가 지적한 아이콘 전용 버튼 세로 44px 누락을 수정하고 기존 검사 기준으로 재확인했다.
- 별도 디자인 탐지기는 기존 반경·서체 크기의 advisory 22건을 보고했다. 이번에 그 값을 바꾸거나 해당 검사를 비활성화하지 않았다. 이 결과와 이번에 해결한 sloplint 경고를 구분한다.

## 출처와 범위

Hallmark는 기존 프로젝트 설치본을 공유하는 프로젝트 로컬 경로를 사용한다. 검사기 변경은 업스트림 변경이 아닌 로컬 패치이며 원래 파일 해시·출처를 INSTALLATION.json에 남겼다. 기존 릴리즈·태그와 shared 결정은 수정하지 않았다. 실기기·보조공학 도구·전체 보안 감사는 수행하지 않았다. 배포 뒤 관측 결과는 DEPLOYMENT.json에 남긴다.
