# v0.1.6 — 핵심 데이터 관계와 설계 흐름 재검토

기록 시각: 2026-11-06 19:33 KST

면접관이 핵심 데이터 관계와 계약·청구·수납의 설계 판단을 빠르게 읽을 수 있도록 기존 아키텍처 페이지를 재검토한다.

- 핵심 관계를 전체 ERD와 구분한 축약 개념도로 보여 주고 상세 설계로 연결한다.
- 계약에서 청구 발행과 수납 확인까지의 경계 및 예외 설명을 기존 코어 설계와 대조한다.
- 문서와 클릭형 프로토타입의 범위를 유지한다. 도식은 구현된 DB 구조가 아닌 설계안이며 보완분의 승인 여부는 미정이다.

검증 결과는 `VERIFICATION.md`에 기록한다.
