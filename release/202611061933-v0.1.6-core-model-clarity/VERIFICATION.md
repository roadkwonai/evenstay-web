# v0.1.6 검증 기록

- 코어 설계 2·3·6·9절과 축약 관계도의 계약 당사자·요금표·청구서·예상 수납·수납 관계를 독립 대조했다. 청구 실행 및 자동이체 동의·배치는 관계표에 별도로 표시한다.
- Archify 3.2.0의 축약 관계도 검증·전달·구조 검사·브라우저 검사를 통과했고 렌더를 확인했다. 전체 ERD가 아닌 설계 개념도다.
- 보호자 동의와 대리인 권한, 확정 수납과 예상 수납, 배치 결과 미확인과 재전송 방지 규칙을 구분했다.
- 문구·용어 검사와 sloplint를 확인했다. 실제 제공자 규격과 현장 정책, 실기기·보조공학 도구는 확인하지 않았다.
- Chrome 1440px·375px의 밝은·어두운 화면에서 6개 주제 앵커, 도식 로딩·원본 링크, 표 포커스와 가로 넘침·콘솔 오류를 확인했다. 모바일에서는 원본 도식을 열어 확대할 수 있다.
