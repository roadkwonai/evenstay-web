# v0.1.8 검증 기록

- 모바일 관계 7개와 계약·청구·수납 단계, 권한·예외를 코어 기술 설계에 대조했다. 핵심 내용의 누락과 의미 손실은 발견하지 못했다.
- Chrome 320·375·1440px, 밝은·어두운 테마와 100·200% 글자 확대에서 가로 넘침·스크립트 오류, 관계 목록과 도식 링크를 확인했다.
- 320px 200% 확대에서 반복 캡션 영역 높이가 144px에서 24px로 줄었고, 원본 도식 링크는 48px 터치 영역과 대상이 포함된 접근성 이름을 유지했다. 키보드 Enter로 새 탭 열림을 확인했다.
- 실제 휴대전화와 스크린리더는 확인하지 않았다. 문서와 도식은 구현 전 설계안이다.
