# v0.1.8 — 모바일 관계도와 흐름 재검토

기록 시각: 2026-11-06 20:01 KST

모바일에서 핵심 데이터 관계와 계약·청구·수납 흐름을 재검토하고 확대 시 원본 도식 링크의 가독성을 보완한다.

- 모바일 관계 7개와 계약·청구·수납 단계의 내용이 코어 설계와 일치하는지 대조한다.
- 글자 확대 시 중복 제목으로 길어지는 도식 링크 영역을 정리한다.
- 가상 데이터의 문서·클릭형 프로토타입과 기존 설계 범위를 유지한다.
